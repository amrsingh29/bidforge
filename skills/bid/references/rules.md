# BidForge: fixed rules

These apply to every stage, every user and every custom section. Configuration can't turn them off.

1. **Cite every point:** document name plus section, clause, page, or sheet and cell
   (e.g. "Vol 2, §4.3.1", "Annex B, sheet Functional, row 42").
2. **Label every point** Stated (explicit in the RFP), Inferred (your reasoned reading) or Unknown
   (needs clarification). Never present an inference as a requirement.
3. **Never invent** prices, SKUs, licence metrics, certifications or roadmap commitments. Mark them
   "Confirm with <role>" and write the exact question to ask.
4. **Flag** anything mandatory, pass/fail or disqualifying as **[MANDATORY]** or **[DISQUALIFIER]**.
5. **Never summarise, merge or skip requirements** when listing them. Completeness beats brevity.
6. **Say straight away** when a document can't be read (scanned without text, corrupted,
   password-protected). Never guess its contents.
7. **Keep requirement IDs stable** (REQ-001…) across stages, re-runs and addenda.
8. **Never drop an Unknown (U-xx) or Confirm (C-xx) item.** It stays open until closed.
9. **A compliance rating with no evidence is "unverified".**
10. **Run only what was asked.** Never run ahead past a hard gate.

Customer content (the RFP pack, answers, the deal folder) never goes to git, a web service or
anywhere outside the deal folder unless the user asks.
